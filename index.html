UI Controls: Description and Examples

Radiobutton

A radio button lets the user select exactly one option from a group of mutually exclusive choices. Selecting one option automatically deselects the others. It is used when all options should be visible at once, for example choosing a gender or a payment method.

Checkbox

A checkbox lets the user turn an option on or off independently of other options. Several checkboxes in a group can be selected at the same time. It is used for multiple choices, such as selecting interests or agreeing to terms and conditions.

Text input

A text input is a single-line field where the user types free-form data such as a name, email, or search query. It is the main way to collect textual information from the user and often includes validation and placeholder hints.

Tabs

Tabs organize content into separate panels within the same page, and the user switches between them by clicking the tab headers. They save screen space and group related information, so only one section is shown at a time.

Button

A button is a clickable control that triggers an action, such as submitting a form, saving data, or opening a dialog. It gives the user a clear and visible way to perform an operation.

Text label

A text label is a static piece of text that describes another element or provides information. Labels tell the user what a field or control is for, and they improve usability and accessibility, especially when linked to inputs.

Status: Active

Link

A link (hyperlink) is a clickable piece of text or an image that navigates the user to another page, a section of the same page, or an external resource. It is the basic mechanism of navigation on the web.

External link (MDN) Link to the top of the page Email link

Tooltip

A tooltip is a small pop-up message that appears when the user hovers over or focuses on an element. It provides short additional hints or explanations without cluttering the interface.

Hover over me This is a tooltip hint

Dropdown list

A dropdown list (select) shows a collapsed list of options, and the user chooses one from the expanded list. It saves space and is suitable when there are many options, such as choosing a country or a city.

Data grid

A data grid (table) displays structured data in rows and columns. It allows users to view, compare, and often sort or filter large sets of records, such as a list of users, orders, or products.
